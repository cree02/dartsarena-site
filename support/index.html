Common questions

The TV scoreboard won't load

The TV (or laptop) must be on the same Wi-Fi as the device running the tournament. Type the address exactly as shown in DartsArena under Admin → Displays & scorers. On iPhone and iPad, check Settings → Privacy & Security → Local Network and make sure DartsArena is turned on. Some guest and public networks block devices from reaching each other; if so, use a different network or a personal hotspot.

My tournament doesn't appear under "Join a tournament nearby"

Both devices need to be on the same Wi-Fi with Local Network access allowed for DartsArena. The host must be running a tournament with "Serve displays on this network" turned on in Admin.

Where do I find the pairing code?

On the device running the tournament, open Admin. The 4-digit code is shown under Displays & scorers. Scorers enter it once when they join.

How do I restore a purchase?

Open Admin (or the Setup screen) → Your version → Restore Purchases, signed in with the Apple Account you bought with. Purchases work on all your iPhones, iPads and Macs, and with Family Sharing.

What does the free version include?

Every feature, for complete tournaments of up to 8 players on 1 board, for your first 2 tournaments. DartsArena Club ($14.99) raises that to 16 players on 2 boards with unlimited tournaments; DartsArena Venue ($34.99) removes all limits. Both are one-time purchases, not subscriptions.

Do scorers need to buy the app too?

No. Only the device running the tournament needs an upgrade. Anyone can download DartsArena for free and join as a scorer.

Which games are supported?

501, 301 and Cricket, played as a single leg or best of 3 or 5, with optional double-out.
